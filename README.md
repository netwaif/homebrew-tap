# homebrew-tap

[netwaif](https://github.com/netwaif) 도구의 Homebrew tap.

## mat — MultiAgent Tracker

[multi-agent-starter](https://github.com/netwaif/multi-agent-starter) 시스템의
작업 진행을 터미널에서 모니터링하는 read-only TUI.

```bash
brew install netwaif/tap/mat
```

설치 후:

```bash
MAT_ROOT=~/VSCodeWorkspace/MultiAgent mat
```

소스: https://github.com/netwaif/mat
